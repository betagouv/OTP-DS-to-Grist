# dn — Module Démarche Numérique

Module regroupant les fonctions liées à Démarche Numérique (ex Démarches Simplifiées).

## Usage CLI

Script de test de connexion et de récupération de données :

```
python -m dn
```

Nécessite les variables d'environnement `DEMARCHES_API_TOKEN` et `DEMARCHE_NUMBER` dans le fichier `.env`.
